# APK（安卓原生壳）使用说明

> 🌐 **语言**：[English](apk.md) · 中文

> **读者**：所有用户。APK 是 dsh Web 界面的**安卓外壳**（WebView 容器），让手机
> 像用 App 一样使用 dsh，而不是打开浏览器。开发者请另读 `apk/README.zh-CN.md`
> （构建、工程结构、限制）。

## 1. 安装

- 手机：安卓 8.0+（API 26+）；
- 从电脑传输 APK 到手机（`adb install` 或直接拷贝安装包点击安装）；
- 首次安装需允许"安装未知来源应用"。

## 2. 首次使用

1. 打开 App → 在同一个界面填写两样东西：
   - **访问地址**：电脑端 dsh 的 Tailscale 地址
     （`https://<机器名>.<tailnet>.ts.net/`，可省略 `https://`）；
   - **Token**（可选）：部署了 remote-config 反代且开启了
     `DSH_PROXY_TOKEN` 时填写（见 `docs/remote-config.zh-CN.md`）。填了
     Token 后 WebView 自动带上，**不会再出现反代的登录页**；
2. 点"连接" → 若手机 Tailscale 未连接，顶部出现黄色横幅，点"打开"跳到
   Tailscale App；连接后横幅自动消失；
3. 界面与手机浏览器完全一致（mobile-fit 全部生效）。**注意：配置/凭据类页面
   （模型、插件、权限、Agent 预设等）默认远程访问 403**，属 dsh 上游安全设计；
   部署 remote-config 反代后可在手机端解锁。

## 3. 日常使用

| 操作 | 方法 |
|---|---|
| 打开会话 | 左上角 ☰ 抽屉，点击会话（不会弹出键盘；点输入框才聚焦） |
| 发送消息 | 右下角箭头（回车是换行） |
| 设置（改地址/改 Token/清数据/常亮） | 左上角 ☰ 下方的 ⚙ 齿轮（仅 APK 内有） |
| 上传文件 | 与网页一致（走系统文件选择器） |
| 下载文件 | 自动存入系统"下载"目录（有通知） |
| 外链 | 自动用系统浏览器打开（壳内只停留 dsh 域名） |
| 返回 | 系统返回键 = 网页后退；无历史时退出 App |

## 4. 更新

新版本安装包覆盖安装即可（debug 与 release 签名不同，**不要混装**：debug 包升级
release 包需先卸载）。

## 5. 已知限制

- 配置/凭据类页面（模型、插件、权限等）默认仅限电脑本机访问（远程 403，dsh
  上游安全设计）；部署 remote-config 反代后可在手机端解锁（见
  `docs/remote-config.zh-CN.md`）；
- 手机必须保持 Tailscale 已连接才能访问电脑；
- "清除缓存与站点数据"会清掉内测声明确认（会再提示一次）；
- 应用界面为浅色风格（设置面板、错误页等）；网页内容深浅色跟随 dsh 页面自身设置。
